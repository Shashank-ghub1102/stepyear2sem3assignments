# Java DSA and Programming Assignments

A collection of Java practice solutions for programming exercises, classroom problems, and algorithmic assignments. The repository is organised by topic and problem category.

## Topics represented

- **Arrays:** common array operations and interview-style problems
- **Control flow:** loops, conditionals, and small console-based exercises
- **Assignment problems:** problem-specific implementations
- **Class problems:** practice problems worked through during learning

Examples in the current source tree include Two Sum, Contains Duplicate, Merge Two Sorted Arrays, Best Time to Buy and Sell Stock, Maximum Subarray, Product of Array Except Self, Three Sum, and Subarray Sum Equals K.

## Requirements

- Java Development Kit (JDK)
- A Java editor or IDE (optional)

## Running a solution

Solutions are individual Java source files. Open the file you want to run and check its class name and whether it expects input. From the directory containing a source file:

```bash
javac FileName.java
java ClassName
```

Replace `FileName.java` and `ClassName` with the actual source filename and class name. If the file declares a package, compile and run it from the appropriate source root using the package-qualified class name.

## Purpose

This repository records ongoing practice with Java syntax, problem decomposition, data structures, and algorithmic thinking. Solutions may represent learning-stage implementations rather than fully optimised production code.
